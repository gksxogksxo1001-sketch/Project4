## 📌 1. 프로젝트 개요
날씨·환율처럼 매일 실제로 변화하는 공개 원천의 실시간 데이터를 조회하고, 외부 네트워크 장애나 API 오류 등 **"데이터가 오지 않을 때"**에도 **마지막 정상값(Last Known Good)을 보존(`stale`)**하며, 실패 유형별로 사용자가 취해야 할 행동을 정직하고 명확하게 안내하는 **무서버(Zero-Backend) 회복 탄력적(Resilient) 정보판**입니다.

- **실시간 데이터 원천 (No-Key)**:
  - 🌡️ **서울 기온**: Open-Meteo 공개 날씨 API (`https://api.open-meteo.com`)
  - 💵 **원/달러 환율**: ExchangeRate-API 공개 환율 엔드포인트 (`https://open.er-api.com`)
- **기준 시간대**: 대한민국 표준시 **Asia/Seoul (KST, UTC+9)**
- **기술 스택**: Vanilla JavaScript (ES6+), HTML5, Tailwind CSS, Lucide Icons, LocalStorage

## 🛠️ 3. 5대 합성 실패 시뮬레이터 & 대응 매뉴얼 (카드 3)

| 실패 유형 | error_code | 시스템 원인 분석 | 사용자 다음 행동 가이드 |
|:---|:---|:---|:---|
| ⏳ **느린 외부 응답** | `ERROR_TIMEOUT` | 응답 지연(3초 초과 Abort) 발생 | "네트워크 대역폭 상태를 점검한 뒤 **[다시 시도]**를 누르세요." |
| 🚫 **외부 원천 401/403 거절** | `ERROR_FORBIDDEN` | 외부 원천 접근 권한 거절 (401/403) | "원천 API 공개 엔드포인트 URL 정책 변경 여부를 확인하세요." |
| 🛑 **호출 제한 (Rate Limit)** | `ERROR_RATE_LIMIT` | 요청 한도(429 Too Many Requests) 초과 | "1분간 호출을 중단하거나 30초 자동 갱신 스위치를 잠시 끄세요." |
| 🔌 **오프라인 상태** | `ERROR_OFFLINE` | 인터넷 끊김 (`Failed to fetch`) | "브라우저 및 로컬 인터넷 연결 상태를 확인하고 **[다시 시도]**하세요." |
| 🧩 **응답 형식 변경** | `ERROR_SCHEMA_MALFORMED` | 응답 JSON 구조 파괴 / 필수 필드 누락 | "데이터 정규화 파서 규격을 최신 응답 포맷에 맞게 점검하세요." |

## 📝 4. 심사위원 공식 제출 증거 (카드 5)

### 📌 [T04-C27] 짧은 확인 방법 4줄 규격
1. **① 어디로 가나요**: 상단 **'외부 실패 5종 합성 재생'** 패널 및 중앙 **메인 지표 카드**
2. **② 3단계 이내 무엇을 하나요**: **[호출 제한(429)]** 클릭 ➔ **[지금 조회하기]** 클릭 ➔ 상태 배너 및 지표 카드 확인
3. **③ 무엇이 보이면 통과인가요**: 상단에 `⚠️ [ERROR_RATE_LIMIT] 호출 제한` 상태와 사용자 대처 안내가 표시되고, 기존 수치에 `[stale]` 뱃지가 붙으며 마지막 정상값이 지워지지 않고 보존됨
4. **④ 안 될 때 무엇이 보이나요**: 화면이 백지로 변하거나 수치가 0, NaN, 빈칸으로 소실되는 경우

---

### 📌 [T04-C28] 제출문 3줄 규격
1. **① AI에게 맡긴 일**: No-Key 공개 API 통신 모듈(Open-Meteo, ExchangeRate)과 5대 실패(Timeout, 401/403, 429, Offline, Malformed) 합성 시뮬레이터 및 T04-RECOVER-D2 복구 로직 코드 작성
2. **② 학생이 직접 판단한 일**: 카드 4의 Asia/Seoul 하루 한 줄 Upsert 규칙(같은 날 행 수 불변 검증기)을 배치하고, 카드 5의 이틀 치 변화량 수식을 정밀 대조할 수 있도록 3단 일치 대조 뷰어(Raw - Storage - DOM)를 기획함
3. **③ AI 제안을 따르지 않은 일**: 백엔드 프록시 서버나 별도 데이터베이스를 두자는 초기 제안을 배제하고, 무로그인 시크릿 창 정적 배포 기준(Zero-Backend)을 고수함
