## 1. 프로젝트 개요
- **목적**: 날씨·환율처럼 실제로 매일 변하는 실시간 데이터를 조회하고, 외부 네트워크나 API 장애(데이터가 오지 않을 때)가 발생해도 **마지막 정상값을 보존(`stale`)하면서 현재 상태와 실패 유형별 사용자 다음 행동을 정직하게 설명**하는 회복 탄력적(Resilient) 정보판을 구축한다.
- **배포 환경**: 무로그인 정적 배포 (GitHub Pages / Vercel), 새 시크릿 창에서 1초 만에 즉시 실행 (T04-C01).
- **기술 스택**: Vanilla JS, HTML5, Tailwind CSS, Lucide Icons, LocalStorage.

## 3. 핵심 기능 명세

### 3.1. 실패 유형별 상태코드 및 사용자 행동 가이드 (카드 3)
| 실패 유형 | error_code | 시스템 설명 | 사용자가 취할 다음 행동 안내 |
|---|---|---|---|
| **느린 응답** | `ERROR_TIMEOUT` | 응답 지연(3초 초과)으로 연결이 중단되었습니다. | "네트워크 대역폭 상태를 점검한 뒤 [다시 시도]를 누르세요." |
| **401/403 거절** | `ERROR_FORBIDDEN` | 외부 원천 접근 권한이 거절되었습니다 (401/403). | "원천 API 공개 엔드포인트 URL 정책 변경 여부를 확인하세요." |
| **호출 제한** | `ERROR_RATE_LIMIT` | 원천 API 요청 한도(429 Too Many Requests)를 초과했습니다. | "1분간 호출을 중단하거나 30초 자동 갱신 스위치를 잠시 끄세요." |
| **오프라인** | `ERROR_OFFLINE` | 인터넷 연결이 끊겨 원천 호스트에 접속할 수 없습니다. | "브라우저 및 로컬 Wi-Fi/유선랜 연결 상태를 확인하고 [다시 시도]하세요." |
| **형식 변경** | `ERROR_SCHEMA_MALFORMED` | 응답 JSON 구조가 변경되었거나 필수 수치 필드가 누락되었습니다. | "데이터 정규화 파서 규칙을 최신 응답 포맷에 맞게 점검하세요." |

### 3.2. RECOVER-D2 복구 엔진 (T04-C19)
- 실패 상태에서 [T04-RECOVER-D2 복구 재생] 버튼을 클릭하면:
  - `state.isDegraded = false`
  - `state.error_code = 'none'`
  - `metricFreshness = 'fresh'`
  - **다음 날짜(D2, 내일 KST)의 정상 일별 기록이 정확히 1건 추가**되어 총 일별 기록 수가 2건으로 증가하고, 어제 대비 변화값(Delta)이 갱신됨.

### 3.3. Asia/Seoul KST 하루 한 줄 Upsert 엔진 (카드 4)
- 날짜 키를 `YYYY-MM-DD (Asia/Seoul)`로 생성.
- 오늘 날짜로 10번 조회하더라도: `dailyHistory[todayKey]`가 갱신만 되므로 **행 수는 항상 1건 유지** (`T04-C20`).
- 다음 날짜(D2)로 조회 시에만 새로운 행이 생성되어 총 2건으로 증가 (`T04-C21`).
- 심사위원용 [🧪 같은 날 3회 재실행 시험 (T04-C20)] 도구를 통해 실행 전후 행 수가 1행으로 동일함을 눈으로 즉시 증명.

### 3.4. 과제 제출 증거 템플릿 (카드 5: T04-C27, T04-C28)
- T04-C27 준수 4줄:
  1. ① 어디로 가나요: 상단 '외부 실패 5종 합성 재생' 패널 및 중앙 메인 지표 카드
  2. ② 3단계 이내 무엇을 하나요: [호출 제한(429)] 클릭 -> [지금 조회하기] 클릭 -> 상태 배너 및 지표 카드 확인
  3. ③ 무엇이 보이면 통과인가요: 상단에 "⚠️ [ERROR_RATE_LIMIT] 호출 제한" 상태와 사용자 대처 안내가 표시되고, 기존 수치에 [stale] 뱃지가 붙으며 마지막 정상값이 지워지지 않고 보존됨
  4. ④ 안 될 때 무엇이 보이나요: 화면이 백지로 변하거나 수치가 0, NaN, 빈칸으로 소실되는 경우
- T04-C28 준수 3줄:
  1. ① AI에게 맡긴 일: No-Key 공개 API 통신 모듈 및 5대 실패(Timeout, 401/403, 429, Offline, Malformed) 합성 시뮬레이터와 T04-RECOVER-D2 복구 로직 작성
  2. ② 학생이 직접 판단한 일: 카드 4의 Asia/Seoul 하루 한 줄 Upsert 규칙(같은 날 행 수 불변 검증기)을 배치하고, 카드 5의 이틀 치 변화량 수식을 정밀 대조할 수 있도록 3단 일치 대조 뷰어를 기획함
  3. ③ AI 제안을 따르지 않은 일: 백엔드 프록시 서버나 별도 데이터베이스를 두자는 초기 제안을 배제하고, 무로그인 시크릿 창 정적 배포 기준(Zero-Backend)을 고수함
